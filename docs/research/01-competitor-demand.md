# 竞品与需求验证：AIHOT 及大学生信息聚合赛道的真实格局

> **结论前置**：① 卡兹克的 AIHOT 不是「资讯站」，而是一套**已开源、已被验证可复制的垂直聚合适配器**（MIT、11,340★、2,631 fork）；② 大学生赛道已有四类玩家，但**没有一家在做「报名/考试的时间轴 + 原文可核查」**，这是唯一的空隙；③ 这个赛道的死法高度一致——停更、内容过期、沦为软文壳、被官方站替代，四条都有一手证据；④ 判断：**进入，但放弃「竞赛资讯门户」，改做「考证/竞赛的可核查时间轴 + 日历订阅 + 开源框架」**。

---

## 1. 卡兹克与 AIHOT：一个已经跑通的「垂直聚合」范式

### 1.1 它到底是什么

AIHOT（aihot.news）是「数字生命卡兹克」出品的 AI 新闻精选站。官方自述的工作方式是：盯着 **924 个信源**（X 549、RSS 179、网页 145、公众号 23、接口 27），累计收录 **64.7 万条**动态，用模型预筛、独立两次打分、把同一件事的多篇报道聚成一个事件，**每天早上 08:00 出一份 AI 日报，免费、不用注册**，已出 **217 期**（[aihot.news/about](https://aihot.news/about)）。站点还提供 RSS、REST API、MCP、Agent Skill 四种机器读取方式，全部匿名只读（[aihot.news/agent](https://aihot.news/agent)）。

运营主体是**北京虚实空际文化科技有限公司**，备案号 京ICP备2026012723号-5（[aihot.news/privacy](https://aihot.news/privacy)）——不是个人玩具，是公司化运营。

### 1.2 它怎么做的（可逐条核查）

引擎**完整开源**：KKKKhazix/AIHOT，MIT 协议，TypeScript，Node 24 + PostgreSQL 17 + Docker Compose 五容器（db/setup/api/worker/web），**11,340 star、2,631 fork**，2026-09-28 建仓，2026-11-24 仍在推送（[github.com/KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT)、[API 元数据](https://api.github.com/repos/KKKKhazix/AIHOT)）。

架构上有三处对我们直接可用：

1. **六种信源适配器**：rss / web_list（CSS 选择器）/ json_list / x_search / mp_account / external（自建脚本推送），每种都有配置校验和「试抓预览」（[docs/sources.md](https://github.com/KKKKhazix/AIHOT/blob/main/docs/sources.md)）。
2. **「预筛 → 同标准独立打两次分 → 结构化 → 写作 → 聚簇」的流水线**，提示词全部落在 industry/prompts/ 下，改标准不用改代码（[docs/selection.md](https://github.com/KKKKhazix/AIHOT/blob/main/docs/selection.md)）。
3. **成本可估算**：示范信源首次导入 152 条资料，约 **930 次模型调用**；日报按规则编排、不调用模型（[docs/deploy.md](https://github.com/KKKKhazix/AIHOT/blob/main/docs/deploy.md)）。

作者在 README 里写明自己是设计师出身、半年前还看不太懂代码，这套代码是他和 AI 一起重写的（[README](https://github.com/KKKKhazix/AIHOT/blob/main/README.md)）——**复杂度落在一个非科班 + AI 辅助的人可完成的范围内**。

### 1.3 为什么能火（区分为「一手可证」与「推断」）

- **可证**：免费 + 不用注册（[about](https://aihot.news/about)）；每天固定 08:00 出刊形成节律；把「信源→精选」的标准全部公开，可被信任；开源把「读者」转成「共建者」，README 直接给出「把信源换成你的，它就是你的行业热点站」的改造路径（[README](https://github.com/KKKKhazix/AIHOT/blob/main/README.md)）。
- **可证**：迭代密度高，更新日志显示 11 月内有 6 天连续上线新功能（[changelog](https://aihot.news/changelog)）。
- **推断（无一手数据，标注为未核实）**：11,340 star 里有相当比例来自作者既有的公众号/知乎受众导流。作者在 README 中说「这半年，很多做法律、做 HR、做金融、做贵金属的朋友问我，能不能也给他们的行业做一个」——这只说明他有跨行业的读者面，**不能证明** star 的转化率。

### 1.4 能迁移什么、不能迁移什么

**能迁移**：信源适配器分层、双次打分、事件聚簇、日报/周报编排、MCP/RSS/API 三件套、「每条附原文链接」的可核查设计。
**不能迁移**：个人 IP 带来的冷启动流量；以及 AI 行业的「日更密度」——AI 一天几十条新闻，而**考证/竞赛是低频、强周期**的，日报模型在这里是错配的（详见第 3 节）。

## 2. 竞品横切：四类玩家，没有一类在解决「时间」

| 玩家 | 解决了什么 | 没解决什么 |
|---|---|---|
| 赛氪 / 我爱竞赛网 / 竞赛通知网 | 赛事「有没有、什么时候报」 | 报名要跳他们的系统；时间字段不结构化、不可订阅；过期内容不清理 |
| NEEA / 学信网 / 软考 / 人事考试 | 各自领域的**权威**报名与查分 | 各自为政，**没有跨部门的考证日历** |
| 牛客 / 实习僧 / BOSS / 智联校园 | 求职与笔试 | 完全不覆盖「考证/竞赛」这一层 |
| GitHub 开源同类 | 单点工具（榜单、OJ） | 无一做到「持续维护 + 多校覆盖」 |

### 2.1 赛事聚合与报名平台

**赛氪**（saikr.com）自述「为各专业的大学生提供了 **3 万多项**竞赛」，并为《全国大学生英语竞赛》《MathorCup》等提供**在线报名系统**（[m.saikr.com/vs](https://m.saikr.com/vs)）。它的真实身份是**报名 SaaS + 赛事服务商**：页面按「离报名截止还有 N 天」展示，但字段锁在详情页里，没有 .ics、没有按专业的结构化筛选，主办方里混着商业机构（同上）。

**我爱竞赛网**（52jingsai.com）是 **Discuz! X3.2 论坛**改的门户（[robots.txt](https://www.52jingsai.com/robots.txt) 直接暴露 Discuz 目录），页脚版权写 2014-2025（[首页](https://www.52jingsai.com/)）。分类极细（22 个赛道 + 34 个地区），但**二手转载**特征明显：标题里直接塞「【数学竞赛，12月4日报名截止】」这类前缀（[比赛信息](https://www.52jingsai.com/bisai/)）。

**竞赛通知网**（jingsaitongzhi.com）是这批里最接近我们想法的：115 个竞赛、有**报名截止日历**、明确写「重要日期均提供原始来源」「不提供报名代理」，并主动声明「赛事被平台收录，不代表所有高校均予认可」（[关于](https://jingsaitongzhi.com/about)、[日历](https://jingsaitongzhi.com/calendar)）。但它的商业模式是**竞赛辅导**（页头常驻「添加微信…备注竞赛名及需求」），信息只是获客入口；且备案 渝ICP备2026002868号-5，是 2026 年新站，覆盖深度未经验证。

### 2.2 官方权威源（最容易被低估的对手）

官方不是「没做聚合」，而是**各自做了垂直聚合**：

- **中国教育考试网**统一覆盖四六级、计算机等级（NCRE）、教师资格（NTCE）、书画等级等，且每项都有独立子站与报名/查分入口（[neea.edu.cn](https://www.neea.edu.cn/)、[cet.neea.edu.cn](https://cet.neea.edu.cn/)、[ncre.neea.edu.cn](https://ncre.neea.edu.cn/)、[ntce.neea.edu.cn](https://ntce.neea.edu.cn/)）。
- **软考**在工信部教考中心独立站点（[ruankao.org.cn](https://www.ruankao.org.cn/)）；**专业技术人员职业资格**在人社部人事考试网（[cpta.com.cn](http://www.cpta.com.cn/)），并明确「2021 年版《国家职业资格目录》共 72 项，除此之外任何机构不得再自行设置职业资格」（[关停假冒网站，治理「山寨证书」](http://www.cpta.com.cn/notice/1146.html)）。
- **学信网**把学籍/学历/学位、研招、阳光高考、**国家大学生就业服务平台**全部收在一处（[chsi.com.cn](https://www.chsi.com.cn/)）；后者进一步把**省级、校级就业网**做成可切换的分站（[ncss.cn](https://www.ncss.cn/)）。
- **高校侧**是最碎的一层：杭电教务处「学科竞赛」栏目有 **205 条记录、15 页**，且与「获奖名单公示」混排（[jwc.hdu.edu.cn/xkjs/list.htm](https://jwc.hdu.edu.cn/xkjs/list.htm)）；上海交大教务处的通知公告首页 30 条里，没有一条是竞赛报名（[jwc.sjtu.edu.cn](https://jwc.sjtu.edu.cn/)）——竞赛通知散在创新创业学院、团委、各学院，**不在一个入口**。

**结论**：官方源在「权威性」上不可战胜，但在「**跨部门横切 + 时间轴 + 可订阅**」上是空白。这是唯一可站的位置。

### 2.3 求职侧

**牛客**是「题库 + 面经 + 笔试真题 + 竞赛 OJ」的复合体：ac.nowcoder.com 有独立比赛日历与 Rating 榜（[ac.nowcoder.com](https://ac.nowcoder.com/)），主站按公司聚合笔试真题（[nowcoder.com/exam/company](https://www.nowcoder.com/exam/company)）。
**实习僧**自述 **2100 万学生用户、3000 所高校、30 万企业**（[shixiseng.com/about](https://www.shixiseng.com/about)）。
**BOSS 直聘**有独立校园频道（[zhipin.com](https://www.zhipin.com/)），**智联校园**按专业做了一套极细的职位分类树（[xiaoyuan.zhaopin.com](https://xiaoyuan.zhaopin.com/)）。

这一格**没有我们的位置**：官方有 ncss.cn，商业侧有 2100 万用户级的平台，且招聘涉及人力资源服务资质。**建议直接放弃自建招聘，只做外链索引**。

## 3. 需求真实性：证据与证据缺口

### 3.1 供给侧碎片化是可测量的（强证据）

同一件事——「今年有哪些比赛、什么时候截止」——学生至少要跳 **6 个互不相通的系统**：NEEA（四六级/计算机/教资）、软考官网、人事考试网（专业资格）、学信网（研招/就业）、本校教务处（学科竞赛，如杭电 205 条混排）、主办方官网（如数模 [mcm.edu.cn](https://www.mcm.edu.cn/)）。**没有任何一个入口能回答「我这个专业，未来 3 个月有哪些证和赛要报名」**。

规模侧：2026 年全国大学生数学建模竞赛有 **1,963 所院校、89,543 队、26 万多人**报名（[mcm.edu.cn](https://www.mcm.edu.cn/)）；实习僧覆盖 3000 所高校、2100 万学生（[about](https://www.shixiseng.com/about)）。这说明**单个赛事的峰值需求极大，而需求在时间上高度集中**——正是日历型产品的最优场景。

### 3.2 但「痛点存在」≠「愿意迁移」（必须诚实标注的缺口）

我没有找到任何**公开的、可引用的大学生信息获取渠道调研**（问卷、论文、平台后台数据）。搜索结果里关于「信息差」的内容几乎全是自媒体转述，不能作为一手证据。**因此「信息闭塞有多痛」这一条，目前只能证明「供给是碎的」，不能证明「学生愿意为此换一个网站」。**

这一点直接影响结论：**不要做「内容站」（靠流量变现），要做「工具」（靠日历订阅与嵌入式使用）**，因为工具的价值不需要用户「信任一个新媒体」。

## 4. 反面证据：这个赛道最常见的四种死法

### 4.1 停更

MLCompetitionHub 是中文圈最知名的机器学习竞赛聚合项目，132 star、24 fork，最后一次提交停在 **2023-09-21**，仓库至今未归档但已无人维护（[commits](https://github.com/LogicJake/MLCompetitionHub/commits/master)、[API](https://api.github.com/repos/LogicJake/MLCompetitionHub)）。awesome-rl-competitions 拿到 347 star 后**直接归档**（[repo](https://github.com/seungjaeryanlee/awesome-rl-competitions)）。

**死因**：靠人工维护的列表，一旦作者毕业/换工作就死。**对策**：抓取必须自动化，人工只做「纠错」不做「录入」。

### 4.2 内容过期

> **【红队更正 · 2026-11-24】** 本段原写"首页挂着 2016 年 11 月 24 日截止的条目、已过期 9 年"。红队复测：该条原文是 **"报名截止时间：2026年11月21日 中午12点"**，发布日 2026-11-16，整页 HTML 中 "2016" 零命中（首页 16 个日期全部落在 2026-09-22 ~ 2026-11-21）。**原文把 2026 误读为 2016，"9 年前"这条证据不成立。**
>
> 可保留的弱证据只剩：该条目在截止后 **3 天**（11-21 截止，11-24 仍在首页）未被标记结束或移出主列表。这只能说明"过期内容清理有滞后（以天计）"，**不足以支撑"内容过期"作为一条独立死因**。

**修正后的判断**：本节降级为"待观察风险"，不作为反面证据引用。四类死法里真正有硬证据的仍是 **4.1 停更**（MLCompetitionHub 停更 3 年、awesome-rl-competitions 归档）、**4.3 沦为软文**（ijingsai.cn 首页全是 GEO 软文）、**4.4 被官方替代**（ncss.cn 收编省校两级就业网）、**4.5 一次性项目**（6 仓库中 4 个 star≤5、2 个 48 小时内停更）。

**死因**：只增不删，索引变成垃圾场。**对策**：过期条目必须降级为「已结束」并移出主列表，但**保留 URL**（保 SEO 与历史查询）。

### 4.3 沦为软文 / SEO 壳

**爱竞赛网**（ijingsai.cn）自称「大学生竞赛资讯第一门户」，但当前首页的「最新文章」是《抢占 AI 关键词搜索排名：GEO 如何重塑企业营销新逻辑》《厦门媒体发稿与软文发布实战指南》《未央区哪家少儿英语口碑最好》《2026 长春本科学校哪家好【本地报考参考】》（[ijingsai.cn](https://www.ijingsai.cn/)）——**已经完全退化为本地 SEO 软文站**。

**大学生竞赛信息网**（daxueshengjingsai.com.cn）更极端：把**中国国际大学生创新大赛**的官方简介整段搬来当自己的组织简介，联系方式写的是 ccf.org.cn 的邮箱，版权方却是「海南童雄达投资集团有限公司」（[about](https://daxueshengjingsai.com.cn/about)）。

**死因**：信息本身不产生收入，只能卖流量，卖流量就会劣币驱逐良币。**对策**：明确「不接返佣、不做付费排名」，把商业模式放在「框架/托管/服务」而不是「广告位」。

### 4.4 被官方平台替代

ncss.cn 已经把**省级就业网、校级就业网**做成可切换分站，并与国聘、中智、前程无忧、BOSS、智联、实习僧等联合办招聘会（[ncss.cn](https://www.ncss.cn/)）。学信网把研招、阳光高考、学职平台全部收编（[chsi.com.cn](https://www.chsi.com.cn/)）。**任何「校园招聘聚合」或「考研信息聚合」的独立站点，都会被这两个入口正面碾过。**

**死因**：选了官方已经在做的垂直。**对策**：只做官方**做不了**的横切面——跨部门时间轴、跨校通知归一、变更 diff。

### 4.5 一次性项目

第 2.4 节本身就是反面证据：6 个同类仓库里**4 个 star ≤ 5，2 个在 48 小时内停止提交**。这个赛道不缺想法，缺的是**活过第三个月的人**。

## 5. 结论：进入，但换切入点

### 5.1 判断：**进入**，但**不做「竞赛资讯门户」**

理由三条：
1. 需求侧的「供给碎片化」有硬证据（6 个互不相通的官方系统、杭电 205 条混排通知），而**没有任何竞品在解决「时间」**——赛氪卖报名、我爱竞赛网卖广告、竞赛通知网卖辅导，三家都不做可订阅的结构化时间轴。
2. 供给侧的**技术路径已被 AIHOT 验证可行且成本可控**（六种信源适配器、152 条约 930 次模型调用、MIT 可复用）。
3. 但「内容站」路径被 4.3 和 4.4 堵死——所以**不能靠内容流量**。

### 5.2 切入点：把产品定义成「时间轴 + 溯源 + 订阅」，而不是「资讯流」

| 做 | 不做 |
|---|---|
| 每条记录必带 official_url + fetched_at + last_verified_at | 不做全文转载、不做二手编辑稿 |
| 报名/考试日期做成**结构化字段**，导出 .ics、支持按 tag 订阅 | 不做「猜你喜欢」式推荐 |
| 过期条目降级为「已结束」但保留 URL | 不做报名系统、不代收费用 |

### 5.3 三条否决线（任何一条触发就停）

1. **抓取覆盖率 < 60%**：自动化覆盖不到六成、剩下靠人工，必然重蹈 4.1 的覆辙。
